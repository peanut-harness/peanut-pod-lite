# Spec Delta

## Purpose

规定 Lite 宿主中已安装插件的业务工作流行为，使用户能在独立槽位持续编辑，将 UI Prefab 控制器和字体输出保存并导入真实 Creator 工程，且失败状态与文件结果一致。

## ADDED Requirements

### Requirement: 独立槽位编辑

宿主 SHALL 保持各槽位的插件身份和未保存编辑状态独立。

#### Scenario: 关闭其他槽位并重复加载
- **GIVEN** A、B、C 各自已加载活动插件，B、C 存在未保存输入
- **WHEN** 关闭 A 并重复加载 C 的同一活动插件
- **THEN** B、C 输入不重置且请求可用；关闭再打开 C 时按插件初始化规则恢复

#### Scenario: 非法调用
- **WHEN** 请求包含无效槽位、停用插件、旧页面身份或逃逸路径
- **THEN** 宿主拒绝请求且不修改其他槽位或工程资源

### Requirement: 规则与控制器可用

宿主承载的 UI Prefab 工作流 SHALL 将保存规则与生成绑定结果持久化为 Creator 可读取的资源。

#### Scenario: 保存和重复绑定
- **GIVEN** 独立策略及含节点、组件、按钮的最小 Prefab
- **WHEN** 编辑规则后保存重开，并生成控制器、绑定两次
- **THEN** 规则一致，组件不重复挂载，节点引用与按钮事件正确，同一目标、组件、方法和参数的事件复绑仅保留一次且其他事件保留，Creator 导入或编译成功

#### Scenario: 绑定路径选择
- **WHEN** 分别使用可用的 MCP 绑定和声明的离线回退
- **THEN** 两条路径满足相同引用契约，同名节点按路径消歧，缺少组件遵循既有降级，无效路径被拒绝

### Requirement: SDF 生成导入

宿主承载的 SDF 工作流 SHALL 将有效生成结果导入受控工程资源目录并返回对应真实文件的状态。

#### Scenario: 字体生成与回读
- **GIVEN** 可用字体和短字符集
- **WHEN** 使用当前支持的字段类型生成、预览、保存和导入
- **THEN** 图集尺寸、字符和配置可回读，Creator 识别资源，窄短窗口可达关键操作

#### Scenario: 无效输入
- **WHEN** 字体、字符或输出路径无效
- **THEN** 显示可理解的失败状态，不将缺失或无效输出标记成功

### Requirement: SnowB 保存发布

宿主承载的 SnowB 工作流 SHALL 将当前字体工程保存为可重开的文件并发布有效字体与纹理资源。

#### Scenario: 保存重开发布导入
- **GIVEN** 具有字体、字符和图集设置的最小 SnowB 工程
- **WHEN** 保存、关闭、重新打开，再发布并导入 Creator
- **THEN** 数据和设置保留，字体与纹理有效且可使用，成功提示与文件、宿主响应一致

#### Scenario: 导出源缺失
- **WHEN** 当前面板不能提供有效工程导出源
- **THEN** 发布明确失败，不产生伪造成功或占位字体
