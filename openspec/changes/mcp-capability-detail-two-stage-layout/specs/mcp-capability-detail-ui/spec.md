# Spec Delta

## Purpose

为 MCP 能力目录提供清楚的两段式浏览和定义阅读界面，使能力身份保持可见，参数、完整定义和运行记录在停靠空间内仍可访问。

## ADDED Requirements

### Requirement: MCP 能力目录与详情分区
MCP 页面 SHALL 以能力目录和当前能力详情组成两段式布局，并在选择能力后明确显示其完整名称、说明及输入定义。

#### Scenario: 查看能力详情
- **WHEN** 用户从目录选择一项 MCP 能力
- **THEN** 目录保留所选状态，详情区显示所选能力的名称、说明与输入定义

### Requirement: MCP 详情标题固定且内容独立滚动
MCP 详情区 SHALL 固定当前步骤提示和能力名称，并仅在其下方的详情内容区域纵向滚动。

#### Scenario: 阅读长能力定义
- **WHEN** 能力签名、说明、参数或运行记录超过详情区可用高度
- **THEN** 用户可滚动详情内容，步骤提示和能力名称保持可见

### Requirement: MCP 详情内容可切换且保持可访问
MCP 详情区 SHALL 提供输入参数、JSON Schema、审批与最近调用的清楚切换入口；切换 SHALL 保留现有数据和操作行为。

#### Scenario: 切换详情内容
- **WHEN** 用户选择 JSON Schema、审批或最近调用页签
- **THEN** 相应内容在详情滚动区域内显示，且用户可返回输入参数视图

### Requirement: MCP 布局适配停靠尺寸
MCP 页面 SHALL 在较窄的停靠面板中重排目录和详情，避免详情标题、切换入口和内容发生横向溢出或互相覆盖。

#### Scenario: 窄面板阅读
- **WHEN** MCP 面板宽度不足以并排显示目录与详情
- **THEN** 两部分按可用宽度重排，所选能力详情仍可滚动阅读
